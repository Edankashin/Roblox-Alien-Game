# UI checklist (every screen, before it ships)

- [ ] Scale only; no Offset in Position or Size
- [ ] Looks right at iPhone SE size and iPad size in the device emulator
- [ ] Touch targets at least 44 px
- [ ] Text over the world has a stroke; minimum size 14
- [ ] Close button red, top right, same place as every other panel
- [ ] Open and close tweens; press animation; a sound on every tap
- [ ] Colours and font come from the theme module, not the screen
- [ ] Strings come from the strings table
- [ ] Rarity shown by colour and by shape
- [ ] Matches the reference screenshot it was built from (link it)
