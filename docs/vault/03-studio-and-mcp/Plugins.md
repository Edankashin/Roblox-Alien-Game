# Studio plugins we use

- Rojo: code sync. `rojo serve` in the repo, connect in the Plugins tab.
- Stravant GapFill & Extrude: ship module seams, camp parts.
- Stravant ResizeAlign: precise snapping.
- Stravant Redupe: station rows, fences, codex pedestals, hull plates.
- Brushtool 2.1: scattering biome props.
- Archimedes v3: round camp pads, curved hull pieces, arches.

Links in `docs/SETUP.md`. Only the authors named.
