## Rules for the night

- Never stop to ask. If a job is blocked, write why in the log (the exact Output line or error), tick it as `blocked`, and go on to the next one. Come back to blocked jobs at the end.
- Pull before each job (`git pull --rebase origin claude/alien-system-research`); the coordinator pushes fixes between jobs. Push after each job. Never force-push, never rewrite history.
- The code is not yours to change except for the data files a job names (`Shop.luau` ids, `Music.luau`, `Sounds.luau`, `Icons.luau`): bugs go in the log with the Output lines and the coordinator fixes them. Run `./tools/analyze.sh`, `python3 -I tools/lint_data.py` and `./tools/lint.sh` before every push that touches `src/`.
- Spend no Robux and change no account setting. The Open Cloud key stays in the shell (`ROBLOX_API_KEY`, `ROBLOX_OPEN_CLOUD_KEY`): never print it, never write it anywhere.
- Studio without Rojo Connect: build the place from the repo and open the file (`rojo build default.project.json -o build/world1.rbxl && open build/world1.rbxl`). The three projects differ only in the Workspace attribute `WorldId` (1, 2, 0), so switch worlds in the same window with `workspace:SetAttribute("WorldId", 2)` in Edit mode (execute_luau, Edit datamodel), then Play. The runtime model loader fills the models at Play (`Models:` line in Output). After a pull that changed `src/`, rebuild and reopen the file (close the old Studio window first: `osascript -e 'tell application "RobloxStudio" to quit'` while not in Play; if it asks to save, the window is fine to lose).
- Dev commands in Play: from the Client datamodel `game:GetService("TextChatService").TextChannels.RBXGeneral:SendAsync("/scrap 1000")`, one command per execute_luau call. Server Output lands in `~/Library/Logs/Roblox/*_last.log`.
- Each result line: milestone, step, pass or fail, the exact Output line that proves it, what you saw. Screenshots (`screen_capture`) go to `media/studio/2026-10-14/` as PNG (small, under 1 MB each) when a layout question needs eyes.
- Keep the Mac awake first thing: `caffeinate -dims &`.
