# Roblox engine

What the engine taught us, written so it is only learned once. Several of these notes are generated by a tool in `tools/` (the command is at the top of each note). Back to [[Start-Here]].

## Rules learned the hard way

- [[Service-Boot]]: nothing yields on the boot thread (the Admin subscribe that hung a home place). Read it before adding a service.
- [[Data-Tables]]: shapes in `src/shared/data` that code can walk safely (no string keys in numeric-row tables). Read it before adding a table.
- [[UI-Rules]]: the engine rules for UI (Scale not Offset, strokes, safe areas). Read it with [[UI-Playbook]] before a screen.

## Audits and budgets

- [[Remotes]]: every remote, its rate limit and argument checks (generated by `tools/lint_remotes.py`). Read it before adding or changing a remote.
- [[Exploit-Review]]: the source review of all 60 handlers and the decisions D1 to D8 that came out of it. Read it before touching a handler.
- [[Save-Budget]]: how big a save gets against the 4 MB key limit (generated by `tools/save_budget.py`). Read it before adding anything to the profile.
- [[Performance]]: the per-client budget inventory (generated by `tools/perf_report.py`). Read it before adding a connection, a loop or a part-heavy build.
