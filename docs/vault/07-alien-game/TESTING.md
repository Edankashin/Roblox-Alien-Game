# TESTING (pointer)

The document itself is [`docs/TESTING.md`](../../TESTING.md), outside the vault, so Obsidian cannot open it; this note keeps the `[[TESTING]]` links in the vault working. It holds one test script per milestone, run in Studio with `rojo serve` connected: the steps, the Dev commands to set the state up, and the Output lines and screenshot to report back verbatim. Species are named by id in the commands and by the old display name in some prose (the id-to-name map is in [[Species-Names]]). [[STUDIO-QUEUE]] is generated from it, and the headless checks that need no Studio are in [[Testing-Headless]].
