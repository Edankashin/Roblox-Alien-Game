component is essential for character
movement and animation, making your pet
behave like a game character. Adjust its
properties as needed. Now, for the
magic, scripting the pet to follow the
player. Inside the pet model, add a
script. We'll begin by defining
variables and setting up a basic player
detection loop. Next, we'll implement
the core following logic. We'll create a
loop that constantly finds the player's
position and updates the pet's walk to
point. This ensures your pet always
stays close. Let's create a server
script script to handle pet spawning.
This script detects when a player joins,
automatically spawning and attaching a
default pet for them. It's the core of
pet initialization.

players to select and equip pets. We'll
briefly show adding a screen guey with a
