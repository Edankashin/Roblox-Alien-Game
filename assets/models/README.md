# Models

Exported meshes for Studio import, one folder per species or prop: `assets/models/<SpeciesId>/<SpeciesId>.fbx` plus a `notes.md` with the tool, prompt and triangle count. Built in Blender through MCP (see `docs/vault/06-art-pipelines/Blender-MCP.md`) or generated by the tools in `Creature-Generation.md`. Keep 1 unit = 1 stud and aliens 2 to 3 units tall. Nothing here is loaded by Rojo; Studio imports it through File → Import 3D.

Every species currently has a procedural blockout from `tools/blender/alien_base.py` (GLB and FBX, one mesh, one material slot per colour, 500 to 1,500 triangles) plus `notes.md` with the accessory, tier dressing, triangle count and height. `tools/blender/preview.py` renders `<SpeciesId>.png` (colour) and `<SpeciesId>_grey.png` (solid silhouette) at 256x256 for the greyscale-at-thumbnail check. Regenerate with `python3 tools/blender/alien_base.py --all` and `python3 tools/blender/preview.py`; a hand-made or AI-generated model replaces a blockout by keeping the same folder, file names and height. See `docs/vault/06-art-pipelines/Creature-Generation.md`, section "Blockout tier".

`assets/models/props/<Name>/` holds the 16 scenery and camp props (trees, rocks, shrine stone, pedestal, geyser cone, ship hull, the three stations, the heater lamp), generated by `tools/blender/props_base.py` in the same format as the species (GLB, FBX, `notes.md`, one mesh with a material slot per colour) at 40 to 600 triangles each, standing on z = 0 with the pivot at the bottom centre. Studio imports them into `ReplicatedStorage.Models.Props.<Name>` by hand and the game falls back to part placeholders for any that are missing; regenerate with `python3 tools/blender/props_base.py --all`. See `docs/vault/06-art-pipelines/Map-Dressing.md` for the import and dressing workflow.
